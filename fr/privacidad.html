Politique de confidentialité

Cette politique explique comment les données personnelles sont traitées chez Rojas.clinic conformément au règlement (UE) 2016/679 (RGPD) et à la loi organique espagnole 3/2018 relative à la protection des données personnelles (LOPDGDD).

1. Responsable du traitement

Dre Corina Rojas Gómez. E-mail : corina@rojas.clinic. Localité : Alicante · Communauté valencienne (Espagne). Adresse professionnelle (adresse complète) : [à compléter]. NIF : 13442555K.

2. Quelles données nous traitons et pourquoi

Le formulaire de contact de ce site demande votre nom, votre e-mail et votre message. Ces données sont utilisées uniquement pour répondre à votre demande. Le formulaire n’enregistre pas les informations sur le site : son envoi ouvre votre logiciel de messagerie avec un message adressé à corina@rojas.clinic. Vous pouvez aussi écrire directement à cette adresse. Nous ne demandons pas de données de santé dans le formulaire ; si vous choisissez d’en inclure dans le message, elles ne seront utilisées que pour pouvoir vous répondre.

3. Base juridique

La base juridique de ce traitement est votre consentement (article 6, paragraphe 1, point a), du RGPD), que vous donnez en nous envoyant le message. Vous pouvez le retirer à tout moment en écrivant à corina@rojas.clinic, sans que cela affecte la licéité du traitement déjà effectué.

4. Durée de conservation

Nous conservons le message le temps nécessaire pour vous répondre et, le cas échéant, pour assurer un suivi raisonnable de la demande. Si une relation professionnelle se noue ensuite, les données seront en outre conservées pendant les durées légales applicables.

5. Destinataires

Nous ne cédons ni ne partageons ces données avec des tiers pour leurs propres finalités, et nous ne les vendons pas. Le message transite par le service de messagerie que vous utilisez et par la boîte de corina@rojas.clinic. Le site est hébergé sur GitHub Pages (GitHub, Inc.), qui peut traiter des données techniques (telles que l’adresse IP) uniquement pour servir les pages. Cet hébergement ne reçoit pas le contenu du formulaire.

6. Vos droits

Vous pouvez exercer vos droits d’accès, de rectification, d’effacement, d’opposition, de limitation du traitement et de portabilité en écrivant à corina@rojas.clinic et en indiquant le droit concerné. Si vous estimez que votre demande n’a pas été correctement traitée, vous pouvez introduire une réclamation auprès de l’Agence espagnole de protection des données (www.aepd.es).

7. Sécurité et mineurs

Nous appliquons des mesures raisonnables pour protéger les informations qui nous parviennent par e-mail. Les services du cabinet s’adressent aux personnes majeures. Si vous écrivez au nom d’un mineur, vous devez y être habilité.
